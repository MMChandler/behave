# Behavior Driven Development via Behave Framework
'Behave' is a Gherkin like framework for writing test automation code. The framework is
driven by Selenium.

## Features
Feature files spell out the actions a user would take while doing something in a web app, 
in a reader-friendly way. This is a great reference for any level of an org that wants to know 
what a given test does.

## Steps
Step files define the logic behind the lines of the feature files. For every step of a feature
file, there is a function defined in a step file. Things like finding an element via a webdriver.

## Elements
Locator logic for elements in the UI.
